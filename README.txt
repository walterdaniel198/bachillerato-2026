- icon-192.png / icon-512.png: iconos

PUBLICAR EN GITHUB PAGES
1. Crear un repositorio público nuevo en GitHub.
2. Subir todos los archivos de este paquete a la raíz del repositorio.
3. Abrir Settings > Pages.
4. En Source, elegir Deploy from a branch.
5. Seleccionar la rama main y la carpeta /(root), y guardar.
6. Compartir en WhatsApp la dirección que GitHub Pages muestre.

IPHONE
Abrir la web en Safari > Compartir > Añadir a pantalla de inicio.

ANDROID
Abrir la web en Chrome > menú > Instalar aplicación o Añadir a pantalla de inicio.

Al actualizar horarios o enlaces, editar index.html y cambiar CACHE en sw.js, por ejemplo de bachillerato-v1 a bachillerato-v2.
